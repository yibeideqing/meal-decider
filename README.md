# meal-decider（今天吃什么）

一个 Codex Skill：在“不知道今天吃什么”的时候，根据冰箱现有食材、忌口和当下想吃的口味，推荐 2-3 道现在就能做的菜，并给出 3-5 步的做法。

## 1. 解决什么问题

做饭前的决策成本：冰箱里有东西，但不知道这些能凑出什么菜；想做某个菜，又要为此额外买一堆食材；同时还要照顾忌口和当下口味。

这个技能把“食材清单 + 忌口 + 口味”三件事合并成一次推荐：直接给出 2-3 道现在就能做的菜，并尽量用掉你已有的食材，避免为了做一顿饭再去采购。

## 2. 主要功能

- 从食材出发匹配 2-3 道菜，优先消耗现有食材，尤其是叶菜、豆制品、剩饭剩菜这类不耐放的
- 每道菜给出菜名、“已有/需补”食材清单，以及 3-5 步的简洁做法
- 控制额外采购：默认家里有基础调味料（油、盐、生抽、醋、糖、料酒、葱姜蒜），这些不算“需补”；需补一般以 1-2 样为限，除非用户明确说“可以买”
- 忌口/过敏是硬性过滤条件：先排除全部不合规的菜，再按口味排序；同时覆盖隐性成分（如海鲜过敏要避开蚝油、鱼露、虾皮，不吃辣要避开豆瓣酱、辣油、泡椒）
- 口味偏好参与排序，支持“清淡”“重口味”“想吃面食”这类描述
- 冲突会明说：口味与忌口冲突时（想吃重口味但不吃辣），先指出冲突再给咸香/酱香/蒜香等折中方案；用户列出的食材本身与忌口冲突时（说海鲜过敏却列了虾），指出冲突并剔除该食材
- 食材实在不够时如实说明“这个组合可能做不出完整的菜”，并只列出最少需要补的 1-2 样
- 只在“帮用户选菜”的场景生效：已经知道菜名只问做法、只问营养知识、或在挑餐厅外卖时不会启用

## 3. 安装方法

本机（macOS 当前用户）已经安装好，采用的是软链接方式：

```
~/.codex/skills/meal-decider  ->  <本项目目录>/meal-decider
```

移动或删除本项目目录会让软链接失效，需要重新建立。想改成独立副本，可以先删掉软链接再把整个 `meal-decider/` 文件夹复制进去。

换机器或分享给别人（复制到对方的用户级技能目录即可，技能不依赖脚本或第三方库）：

```bash
cp -R meal-decider ~/.codex/skills/
```

或者用软链接方式：

```bash
ln -s "$(pwd)/meal-decider" ~/.codex/skills/meal-decider
```

安装后在下一次对话即可使用。本项目以 MIT License 开源（见根目录 `LICENSE`），目前尚未发布到任何远程仓库（GitHub 等）。

## 4. 使用方法

直接说需求即可自动触发，例如“冰箱里有鸡蛋、西红柿、剩米饭，帮我决定晚饭”；也可以显式调用 `$meal-decider`。

输入：

- 食材清单（必填，可用自然语言列举）
- 忌口/过敏（选填，如“不吃辣”“海鲜过敏”）
- 想吃的口味/风格（选填，如“想吃清淡的”“想吃面食”）

只给食材清单就够用；口味、份量、调料不用特意说明。如果只说“随便”“你看着办”但没提食材，技能会先问一句家里有什么，再给建议。

输出：

- 固定开场：“根据你的食材和偏好，推荐这几道菜：”
- 2-3 道菜，每道包含菜名、已有食材、需补食材、3-5 步做法
- 固定收尾：“想先做哪一道？我可以给你更详细的步骤。”

## 5. 输入输出示例

**示例一：常规用法**

输入：

> 冰箱里有鸡蛋、西红柿、剩米饭，不吃辣，想吃清淡点

输出：

> 根据你的食材和偏好，推荐这几道菜：
>
> 1. 番茄炒蛋
>    已有：鸡蛋、番茄
>    需补：无需额外采购
>    步骤：1) 鸡蛋加少许盐打散，热油炒至凝固盛出。2) 番茄切块下锅炒出汁。3) 倒回鸡蛋，加盐和少许糖翻匀。
>
> 2. 蛋炒饭
>    已有：鸡蛋、剩米饭
>    需补：无需额外采购
>    步骤：1) 鸡蛋打散炒至半凝固。2) 下米饭压散炒热。3) 加盐翻匀出锅，有葱花可撒一把。
>
> 3. 番茄蛋花汤
>    已有：鸡蛋、番茄
>    需补：无需额外采购
>    步骤：1) 番茄炒出汁后加水烧开。2) 淋入蛋液。3) 加盐调味，撒葱花。
>
> 想先做哪一道？我可以给你更详细的步骤。

**示例二：口味与忌口冲突**

输入：

> 有五花肉、土豆、洋葱，想吃重口味但不吃辣

输出：

> 你想吃重口味但不吃辣，这两条有点冲突，我按咸香、酱香的方向来做，不放任何辣椒。
>
> 根据你的食材和偏好，推荐这几道菜：
>
> 1. 土豆烧肉
>    已有：五花肉、土豆
>    需补：无需额外采购
>    步骤：1) 五花肉切块，冷水下锅焯一下捞出。2) 锅里少油煸出肥油，加生抽和一点糖炒上色。3) 下土豆块翻炒，加热水没过食材，小火炖 20 分钟。4) 大火收汁，加盐调味。
>
> 2. 洋葱炒肉片
>    已有：五花肉、洋葱
>    需补：无需额外采购
>    步骤：1) 五花肉切薄片，洋葱切丝。2) 肉片下锅煸出油。3) 下洋葱大火快炒，加生抽和盐炒匀即可。
>
> 想先做哪一道？我可以给你更详细的步骤。
